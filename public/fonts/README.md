Place licensed font files in this directory:

### Neue Montreal
- `NeueMontreal-Regular.woff2`
- `NeueMontreal-Regular.woff`
- `NeueMontreal-Medium.woff2`
- `NeueMontreal-Medium.woff`

The site already includes `@font-face` rules for these filenames in `styles/globals.css`.
If the files are not present, the UI falls back to DM Sans.

### Libron (home monologue body)
- `Libron-Regular.woff2`
- `Libron-Italic.woff2`
- `Libron-Bold.woff2`
- `Libron-BoldItalic.woff2`

### Noticia Text (home monologue story)
- `NoticiaText-Regular.ttf`
- `NoticiaText-Bold.ttf`
- `NoticiaText-Italic.ttf`
- `NoticiaText-BoldItalic.ttf`

Story line uses Regular only (no italic).
